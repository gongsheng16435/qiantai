# Artwork and credits

The default LUMEN archive uses locally stored atmospheric photographs, not official game covers or game screenshots. Cover typography, layouts, the LUMEN mark, and interface design are original to this project. Game titles identify the entries in a personal collection; no affiliation with their publishers is implied.

The photographs were downloaded from the Unsplash image URLs already referenced by the starter repository. Unsplash permits downloading, modifying, and using photographs for commercial and noncommercial purposes under the [Unsplash License](https://unsplash.com/license); the restrictions on selling unmodified photographs and building a competing image service still apply. These photographs are used as presentation backgrounds within this application.

Source URLs are recorded below so the original images can be traced. No photographer names have been guessed. Assets are retained locally to keep the demo independent of remote image availability.
