# Night Hunt 美术

视觉方向为哥特铜版蚀刻：炭黑、石银、象牙白与少量旧铜。建筑的细密纹理与可读的角色轮廓分层处理，地面亮度经过压低，让刀锋、白色可弹反预警和暗铜红危险预警保持清晰。

## 本地资源

| 资源 | 来源与用途 |
| --- | --- |
| `public/night-hunt/courtyard.webp` | 使用 OpenAI 图像生成工具为本项目生成的原创无人物夜间废墟插画；窗花、钟楼、湿石地面与建筑雾层均在图内。 |
| `public/night-hunt/cover.webp` | 使用游戏的 `renderer.ts` 与 `fighters.ts` 渲染导出；与实战画面共享背景、月亮与角色，仅调整封面人物大小和位置。 |
| `public/night-hunt/cover.svg` | 原版原创程序线描封面，作为图片加载失败时的本地备用。 |

角色、月亮、月蚀、薄雾、脚下阴影、刀光与战斗粒子均由项目代码绘制。没有使用其他游戏的角色图、截图或音轨。所有资源随构建发布，游玩时无需调用图像服务或提供凭据。

## 绘制结构

- `renderer.ts` 将插画、程序化月亮和明暗层合成静态背景；背景加载失败时保留完整的程序线描场景。
- 细雾先烘焙为小纹理，再做轻微位移。二阶段改变雾色与环境色，月蚀遮罩限制在月面内。
- `fighters.ts` 使用缓存的曲线路径和有厚度变化的骨肢，绘制猎人的层叠披衣、帽檐、刀锋，以及守望者的破钟、残冠和弯曲手爪。动作仍由战斗状态驱动。
- 预警与实际判定保持相同范围；深色底衬强化复杂地面上的轮廓。粒子为有方向的短碎屑，避免密集光点盖住人物。
- React 界面使用细刻度、月轮印记与旧铜色点缀；减少动态效果时停用雾层位移和装饰性动画。

如需替换背景，使用无人物、约 16:9 的夜景插画，并为右上方程序绘制的月亮留出天空。地面需可识别，避免在中央可移动区域加入大型障碍。角色、场景或配色发生较大变化时，应同步重新导出 `cover.webp`。
