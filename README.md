# LUMEN — Personal Game Library

A cinematic personal game archive prototype inspired by the restraint and storytelling rhythm of modern Apple product pages and Apple TV interfaces.

## Run

```bash
npm install
npm run dev
```

## Current prototype
- Full-screen dynamic hero
- 20-game typed local dataset
- Artwork-driven horizontal rails
- Personal score/status/playtime metadata
- Editorial light/dark section rhythm
- Timeline/story section
- Framer Motion transitions
- Responsive layout and reduced-motion support

## Artwork note
The current build uses remote atmospheric photo placeholders so the repository does not bundle copyrighted game art. The intended architecture is provider-based and supports later replacement with Steam/IGDB/RAWG metadata or local user-provided artwork.
